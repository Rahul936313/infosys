# Infosys 2027 Prep OS

A Vercel-ready Next.js dashboard for systematic Infosys 2027 placement preparation.

## Included

- 6-phase roadmap from Oct 2026 to Sep 2027
- Local check-off progress with automatic roll-up
- DSA problem bank (arrays, strings, two pointer, sliding window, hashing, bit manipulation, binary search, linked list, stack/queue, heap, trees, BST, graphs, DP, backtracking)
- SQL problem bank
- Core CS interview bank: OOP, DBMS, OS, Computer Networks
- AI/ML interview concepts and questions
- Project execution + project-defense questions
- HR/interview question bank
- Progress export/import as JSON
- Responsive dark placement-command-center UI

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy on Vercel

This is a standard Next.js App Router project. Import the folder into Vercel or run:

```bash
npx vercel
```

For production:

```bash
npx vercel --prod
```

No database or environment variables are required. Progress is stored locally in the browser, with Export/Import buttons for portability.
